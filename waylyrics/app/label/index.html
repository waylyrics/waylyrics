A widget that renders text as vertical columns (tategaki) for the vertical alignment modes.

Normally text is shaped by Pango with Gravity::East so CJK glyphs stay upright, punctuation gets vertical forms and Latin runs are rotated sideways. If the active font has broken/zero vertical advances (vmtx), the widget automatically falls back to stacking upright CJK glyphs with Gravity::South while rotating Latin and bracket/dash runs 90° clockwise. Drawing happens via GtkSnapshot::append_layout so text stays GPU-rendered.
